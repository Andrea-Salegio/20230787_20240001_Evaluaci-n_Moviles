## Descripción del Proyecto
Aplicación móvil interactiva desarrollada con React Native y Expo Managed Workflow. Implementa autenticación segura mediante Firebase Auth (correo y contraseña) y almacenamiento persistente en tiempo real a través de Cloud Firestore. 
 
El proyecto gestiona credenciales sensibles utilizando variables de entorno protegidas (`.env`), componentes de interfaz 100% personalizables y reutilizables (inputs, botones y tarjetas), y un control dinámico del estado de sesión en tiempo real.
